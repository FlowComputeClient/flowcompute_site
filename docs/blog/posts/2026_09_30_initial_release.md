# First Release!

Today is the day of the initial release of FlowCompute. The goal is to bridge Windows and Linux environments, allowing users to handle OpenFOAM workflows without relying on the command line.

Keep in mind that the client's version is 0.9.0. If there are any bugs or major missing features, please add an issue.

FlowCompute supports many, but not all of OpenFOAM's features and utilities. As time progresses, the code will be expanded to encompass more of OpenFOAM's capabilities.
